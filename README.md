# ESM Participa Seguro — Web en GitHub Pages

Publicar SOLO esta carpeta (index.html, styles.css, app.js, config.js, .nojekyll y README.md).

Antes de publicar, editar **config.js** con URL y **publishable/anon key pública** de Supabase. **Nunca** agregar códigos, SQL privados, contraseñas o claves `service_role` a GitHub.

En Supabase debes instalar las funciones SQL privadas, habilitar Anonymous Sign-Ins y autorizar al administrador.

La encuesta no muestra preguntas sin código válido y contraseña compartida. Cada código activa una sola sesión y solo permite un envío. El administrador puede crear lotes nuevos en la pestaña **Códigos**.
